# Trivializing_Maps_Wilson_Flow_HMC_latex

M. Lüscher《Trivializing maps, the Wilson flow and the HMC algorithm》
(Commun. Math. Phys. 293 (2010) 899–911, arXiv:0907.5491) 的英文归一化 LaTeX 转排。

编译：`cd build && xelatex -interaction=nonstopmode -halt-on-error ../main.tex`（两遍）；
或在本目录执行 `xelatex -output-directory=build main.tex`。
