# Lattice_EMT_Fermion_Fields_latex

Normalized English LaTeX re-typesetting of Makino & Suzuki, PTEP 2014, 063B02
[arXiv:1403.4772] ("Lattice energy-momentum tensor from the Yang-Mills gradient
flow - inclusion of fermion fields").

Build:
```bash
cd build && xelatex -interaction=nonstopmode -halt-on-error ../main.tex  # twice
```
(Or from the top dir with `-output-directory=build`.)
