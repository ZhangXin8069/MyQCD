# AGENTS.md

本目录是 Peardon et al., "A novel quark-field creation operator construction
for hadronic physics in lattice QCD" (PRD 80, 054506 (2009); arXiv:0905.2160)
的归一化 LaTeX 转排版（distillation/蒸馏方法奠基论文）。

编译：
```bash
cd build && xelatex -interaction=nonstopmode -halt-on-error ../main.tex  # ×2
```
成品：`build/main.pdf`。详见 `CONVERSION_GUIDE.md`。
