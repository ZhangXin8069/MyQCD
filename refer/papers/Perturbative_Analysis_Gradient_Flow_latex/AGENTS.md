# Perturbative_Analysis_Gradient_Flow_latex

Lüscher & Weisz, "Perturbative analysis of the gradient flow in non-abelian gauge
theories" (JHEP 02 (2011) 051, arXiv:1101.0963) — 英文规范化 LaTeX 转排。

编译：
```bash
cd build && xelatex -interaction=nonstopmode ../main.tex   # 两遍
```
或
```bash
xelatex -interaction=nonstopmode -output-directory=build main.tex
```
