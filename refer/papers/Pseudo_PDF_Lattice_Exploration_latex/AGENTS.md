# Pseudo_PDF_Lattice_Exploration_latex

Orginos–Radyushkin–Karpie–Zafeiropoulos《Lattice QCD exploration of parton pseudo-distribution functions》（PRD 96, 094503 (2017)，arXiv:1706.05373）的规范化 LaTeX 转排（由 arXiv 源码重排为单栏 article）。

编译（两遍）：

```bash
xelatex -interaction=nonstopmode -halt-on-error -output-directory=build main.tex
```
