# Accessing_Gluon_PDF_LaMET_latex

Zhang, Ji, Schäfer, Wang, Zhao, "Accessing gluon parton distributions in large
momentum effective theory", PRL 122, 142001 (2019) 的归一化 LaTeX 转排（英文）。

编译：
```bash
cd Accessing_Gluon_PDF_LaMET_latex && xelatex -interaction=nonstopmode -halt-on-error -output-directory=build main.tex  # 两遍
```
成品：`build/main.pdf`。
