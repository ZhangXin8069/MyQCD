# TRANSLATION_GUIDE

## 来源
- 译自同库英文转排目录 `Trivializing_Maps_Wilson_Flow_HMC_latex/`（arXiv:0907.5491，
  Commun. Math. Phys. 293 (2010) 899–911），逐节忠实翻译全部散文
  （摘要、小节名、图注、脚注式书目行、致谢、附录）。

## 约定
- 文档类 ctexart；字体 AR PL UMing CN / Droid Sans Fallback；
  linespread 1.05 + emergencystretch 3em（防长公式溢出，实测 0 处 Overfull hbox）。
- 数学公式、公式编号（(1.1)…(E.12)）、图表编号与英文版一一对应；宏定义与英文版相同。
- 术语：trivializing map→平凡化映射，Wilson flow→威尔逊流，
  link variable→链接变量，plaquette→方格，smearing→涂抹/光滑化，
  matching 不涉及；renormalization group→重整化群，zero mode→零模，
  spectral gap→谱隙，strict contraction→严格压缩映射。
- 人名、机构地址、参考文献列表保留英文。

## 妥协点
- 致谢段位置随英文版移至文末（致谢 + 附录 A–E + 参考文献），内容完整。
