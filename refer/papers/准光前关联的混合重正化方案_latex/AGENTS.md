# 准光前关联的混合重正化方案_latex

中文译本：Ji et al., "A Hybrid Renormalization Scheme for Quasi
Light-Front Correlations in Large-Momentum Effective Theory",
Nucl. Phys. B 964 (2021) 115311, arXiv:2008.03886。
由 ../Hybrid_Renorm_Quasi_LightFront_latex/（英文转排版）逐节翻译。

编译（两遍，XeLaTeX）：
```bash
cd 准光前关联的混合重正化方案_latex && xelatex -interaction=nonstopmode \
  -halt-on-error -output-directory=build main.tex
```
成品 `build/main.pdf`。
