# Complete_NP_Renorm_QuasiPDF_latex

Alexandrou et al., "A complete non-perturbative renormalization prescription
for quasi-PDFs" (Nucl. Phys. B 923 (2017) 394–415, arXiv:1706.00265)
的归一化 LaTeX 英文转排目录。

编译（需两遍）：

```bash
xelatex -interaction=nonstopmode -halt-on-error -output-directory=build main.tex
```
