# Diffusion_Stochastic_Quantization_latex

论文 "Diffusion Models as Stochastic Quantization in Lattice Field Theory"
(arXiv:2309.17082) 的英文规范化 LaTeX 转排版。

编译：
```bash
cd Diffusion_Stochastic_Quantization_latex && xelatex -interaction=nonstopmode -halt-on-error -output-directory=build main.tex   # ×2
```
成品：`build/main.pdf`。
