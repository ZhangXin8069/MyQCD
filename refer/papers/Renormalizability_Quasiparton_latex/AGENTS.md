# Renormalizability_Quasiparton_latex

Ishikawa/Ma/Qiu/Yoshida《Renormalizability of quasiparton distribution functions》
(PRD 96, 094019 (2017); arXiv:1707.03107) 的英文 LaTeX 转排版。

编译：`cd build && xelatex -interaction=nonstopmode -halt-on-error ../main.tex`（两遍）。
成品：`build/main.pdf`。详见 `CONVERSION_GUIDE.md`。
