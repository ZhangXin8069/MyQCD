# Hybrid_Renorm_Quasi_LightFront_latex

LaTeX 转排：Ji et al., "A Hybrid Renormalization Scheme for Quasi
Light-Front Correlations in Large-Momentum Effective Theory",
Nucl. Phys. B 964 (2021) 115311, arXiv:2008.03886。

编译（两遍）：
```bash
cd Hybrid_Renorm_Quasi_LightFront_latex && xelatex -interaction=nonstopmode \
  -halt-on-error -output-directory=build main.tex
```
成品 `build/main.pdf`。
