# Gluon_Pseudo_Short_Distances_latex

Balitsky/Morris/Radyushkin《Gluon Pseudo-Distributions at Short Distances:
Forward Case》(PLB 808, 135621; arXiv:1910.13963) 的归一化 LaTeX 转排版。

编译：
```bash
cd Gluon_Pseudo_Short_Distances_latex && xelatex -interaction=nonstopmode -halt-on-error -output-directory=build main.tex  # ×2
```
