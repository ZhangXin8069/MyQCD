# AGENTS.md

本目录为论文《非定域夸克双线性算符的格点QCD非微扰重正化》
（Green, Jansen, Steffens, PRL 121, 022004 (2018); arXiv:1707.07152）
的中文 LaTeX 翻译版，逐段译自英文转排目录
`../Nonpert_Renorm_Quark_Bilinears_latex/`。

编译：
```bash
cd 本目录 && xelatex -interaction=nonstopmode -halt-on-error -output-directory=build main.tex  # 两遍
```
成品：`build/main.pdf`。详见 `TRANSLATION_GUIDE.md`。
