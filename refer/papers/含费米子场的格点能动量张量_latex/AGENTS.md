# 含费米子场的格点能动量张量_latex

Makino & Suzuki, PTEP 2014, 063B02 [arXiv:1403.4772] 的忠实中文译本
（原题 "Lattice energy-momentum tensor from the Yang-Mills gradient flow -
inclusion of fermion fields"）。

编译：
```bash
cd build && xelatex -interaction=nonstopmode -halt-on-error ../main.tex  # 两遍
```
（或在顶层用 `-output-directory=build`。）
