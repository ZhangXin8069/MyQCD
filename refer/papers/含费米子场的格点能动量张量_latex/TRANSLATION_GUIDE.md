# TRANSLATION GUIDE

- 来源：arXiv:1403.4772 官方 LaTeX 源码转排的英文版（Lattice_EMT_Fermion_Fields_latex）。
- 逐节忠实翻译全部散文（摘要、标题、小节名、表注、脚注、致谢、附录 A--E）；
  数学公式与编号逐字照抄，章节/公式/图表编号与英文版一一对应。
- 术语约定：gradient flow=梯度流，ringed field=加圈场，trace anomaly=迹反常，
  matching=匹配，renormalization=重正化，flowed field=流动场，
  operator mixing=算符混合，dimensional regularization=维数正规化。
- 人名、机构、参考文献列表保留英文原文；图注为原图代号（C01 等），保持原样。
