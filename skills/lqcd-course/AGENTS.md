# AGENTS.md — lqcd-course 技能

本技能维护格点 QCD 千页级课程：成品文档位于
`docs/lattice_qcd_gluon_tmd_course/`，生成、验证与教学代码位于
`skills/lqcd-course/scripts/`，机器日志位于
`logs/docs/lattice_qcd_gluon_tmd_course/`，可再生视觉数据位于
`data/lattice_qcd_gluon_tmd_course/visual_audit/`。课程包含物理内容、统一编号、
SymPy 证据、论文原页图谱、同源构建和 PDF 全页验收，并引用 `refer/`，但不修改
论文/书籍原文。具体流程与按需验收合同见 `SKILL.md` 和
`references/course-contract.md`。
