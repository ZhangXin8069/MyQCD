# 局限

本页列出算符/图层有意不做的内容。

## 物理

- **不做圈积分。** 包检查传播子、顶点与代数恒等式；不计算费曼积分。
- **不读系综。** 矩阵元、拟合、连续极限外推与物理预言需要格点数据。
- **不分配对称因子。** `myqcd.topology` 只暴露图不变量；对称因子依赖
  粒子内容与交换约定。
- **不做完整重正化。** 提供 RI/MOM 投影器与 Z 因子代数；不提供圈阶系数
  与非微扰拟合。
- **没有 γ5 方案机。** 固定 Euclidean DR 基；未实现 NDR、Larin、BMHV。

## 约定

- `myqcd.color`（$+\delta^{ab}/2$）与历史 `myqcd.derivations`
  （$-\delta^{ab}/2$）的颜色归一化不同。
- Minkowski 与 Euclidean 符号不同；比较数值系数前必须做基变换。
- 历史表中的 `gamma_mu` 代表元是时间分量；请使用显式分量。

## 工程

- 导出格式是结构字符串；不调用外部渲染器。
- 拓扑同构只对不超过 8 个顶点的图精确。
- 缺 `refer/papers/INDEX.md` 时 CLI 优雅降级，但不伪造清单。

## 证据规则

`verified` 只覆盖实际执行的检查。未验证边界显式报告，不藏在全局状态后面。
