# 路线图

当前检查点是精确代数审计层。下一批内容按依赖顺序：

1. **重正化投影器。** 带外线旋量的 $S,P,V,A,T$ RI/MOM 投影器、树级
   归一化与混合矩阵检查。
2. **Wilson 路径代数。** 符号路径排序、staple、Clover 与梯度流算符组合。
3. **图对称因子。** 带显式粒子内容假设的目录，绝不静默自动分配。
4. **匹配核。** 树级与一圈结构核，明确标注未验证边界。
5. **更多可执行实例。** Fierz、颜色迹与拓扑的随机差分测试。
6. **文档覆盖。** API 参考、术语、记号与迁移说明已就位；剩余工作是深度，
   不是导航。
