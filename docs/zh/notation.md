# 记号

| 符号 | 含义 |
|---|---|
| $\mu,\nu,\rho,\sigma$ | Euclidean Lorentz 指标 |
| $\delta_{\mu\nu}$ | Euclidean 度规 |
| $\varepsilon_{\mu\nu\rho\sigma}$ | Levi-Civita，$\varepsilon_{0123}=+1$ |
| $\gamma_\mu$ | Euclidean gamma，$\{\gamma_\mu,\gamma_\nu\}=2\delta_{\mu\nu}$ |
| $\gamma_5$ | $\gamma_1\gamma_2\gamma_3\gamma_4$ |
| $\sigma_{\mu\nu}$ | $\frac12[\gamma_\mu,\gamma_\nu]$ |
| $C$ | $\gamma_4\gamma_2$ |
| $\Gamma_A$ | 16 个 Dirac 双线性之一 |
| $P_{L,R}$ | $(1\mp\gamma_5)/2$ |
| $T^a$ | SU(3) 生成元 $\lambda^a/2$ |
| $f^{abc},d^{abc}$ | 反对称/对称结构常数 |
| $C_F,C_A,T_F$ | SU(3) 下为 $4/3,3,1/2$ |
| $\bar q\,\Gamma q$ | 夸克双线性 |
| $D_\mu$ | 协变导数 |
| $F_{\mu\nu}$ | 场强 |
| $W(x,y)$ | Wilson 线 |
| $L$ | 圈数 $E_{\mathrm{int}}-V+C$ |
| $V,E_{\mathrm{int}},C$ | 顶点、内部边、连通分量 |
| $Z_\Gamma,Z_{ij}$ | 重正化/混合常数 |
| $a$ | 格距 |
| $p_\mu$ | $2\pi n_\mu/L_\mu$ |
| $\hat p^2$ | 格点色散 |
| $m_{\mathrm{eff}}$ | 有效质量 |
| $N$ | 组态数 |
| $\sigma$ | 统计不确定度 |
