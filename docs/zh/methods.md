# 方法学

本页记录本包结论如何产生与检查。

## 精确代数优先

每个矩阵、迹与缩并都是 SymPy 表达式。代数恒等式不使用浮点容差；
`is_zero_matrix` 与 `simplify` 只在显式符号构造之后使用。

## 对偶基与符号

Euclidean 16 双线性基的 Gram 特征值为 $+1$ 或 $-1$。因此 Fierz 投影使用
对偶基 $\Gamma^A=\Gamma_A/g_A$。实现做两次检查：

1. 分量矩阵恒等式
   $\Gamma_A^{ij}\Gamma_B^{kl}
   =\sum_{C,D}F_{AB}^{CD}\Gamma_C^{il}\Gamma_D^{kj}$；
2. 随机复旋量残差小于 $10^{-9}$。

## 随机差分测试

迹恒等式、Fierz 系数与 SU(3) 迹都用带种子的随机指标与显式矩阵乘积对拍。
种子使失败可复现；显式矩阵独立于被测试的捷径。

## 图不变量

拓扑函数只使用顶点、边与粒子标签。圈数为 $E_{\mathrm{int}}-V+C$；
外部腿边不计入。同构对不超过 8 个顶点的图用顶点置换精确判定；更大的图
使用规范签名并声明限制。

## 文档契约

测试套件解析双语 Markdown 并检查：

- 中英文围栏代码块逐字节一致；
- toctree 与磁盘页面集合一致；
- 每个 Python 块可执行；
- 算符表与 `myqcd.operators` 一致；
- SVG 资源存在且格式良好；
- 启用 MathJax/dollarmath；
- 打包文件已被跟踪。

## 审计报告

`python -m myqcd.operator_audit` 运行 48 项检查并写 JSON。`verified` 只对
这些检查成立，不是对圈图、系综或连续极限的声明。

## 发布可复现性

只发布 sdist。sdist 包含两个 README、`py.typed` 与包模块；测试和
`AGENTS.md` 被裁剪。环境无法容纳完整克隆时，用 `git archive` 验证全新
检出构建。

## 方法的边界

这些方法验证精确代数与结构；不替代数值格点数据、圈积分、非微扰重正化
或连续极限外推。
