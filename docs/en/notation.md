# Notation

| Symbol | Meaning |
|---|---|
| $\mu,\nu,\rho,\sigma$ | Euclidean Lorentz indices |
| $\delta_{\mu\nu}$ | Euclidean metric |
| $\varepsilon_{\mu\nu\rho\sigma}$ | Levi-Civita, $\varepsilon_{0123}=+1$ |
| $\gamma_\mu$ | Euclidean gamma, $\{\gamma_\mu,\gamma_\nu\}=2\delta_{\mu\nu}$ |
| $\gamma_5$ | $\gamma_1\gamma_2\gamma_3\gamma_4$ |
| $\sigma_{\mu\nu}$ | $\frac12[\gamma_\mu,\gamma_\nu]$ |
| $C$ | $\gamma_4\gamma_2$ |
| $\Gamma_A$ | one of the 16 Dirac bilinears |
| $P_{L,R}$ | $(1\mp\gamma_5)/2$ |
| $T^a$ | SU(3) generator $\lambda^a/2$ |
| $f^{abc},d^{abc}$ | antisymmetric/symmetric structure constants |
| $C_F,C_A,T_F$ | $4/3,3,1/2$ for SU(3) |
| $\bar q\,\Gamma q$ | quark bilinear |
| $D_\mu$ | covariant derivative |
| $F_{\mu\nu}$ | field strength |
| $W(x,y)$ | Wilson line |
| $L$ | loop number $E_{\mathrm{int}}-V+C$ |
| $V,E_{\mathrm{int}},C$ | vertices, internal edges, components |
| $Z_\Gamma,Z_{ij}$ | renormalization/mixing constants |
| $a$ | lattice spacing |
| $p_\mu$ | $2\pi n_\mu/L_\mu$ |
| $\hat p^2$ | lattice dispersion |
| $m_{\mathrm{eff}}$ | effective mass |
| $N$ | number of configurations |
| $\sigma$ | statistical uncertainty |
