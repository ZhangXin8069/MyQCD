# Roadmap

The current checkpoint is an exact algebraic audit layer. The next content
targets, in dependency order:

1. **Renormalization projectors.** External-spinor RI/MOM projectors for
   $S,P,V,A,T$, tree-level normalization and mixing-matrix checks.
2. **Wilson-path algebra.** Symbolic path ordering, staples, clover and
   gradient-flow operator composition.
3. **Diagram symmetry factors.** A catalog with explicit particle-content
   assumptions, never silent automatic assignment.
4. **Matching kernels.** Tree-level and one-loop structural kernels with
   clearly marked unverified boundaries.
5. **More executable examples.** Random differential tests for Fierz, color
   traces and topology.
6. **Documentation coverage.** API reference, glossary, notation and
   migration notes are already present; the remaining work is depth, not
   navigation.

## Content ledger

## Non-goals

The roadmap does not add a numerical contraction engine, a Mathematica
replacement, a loop-integral library or an ensemble-fit framework.
