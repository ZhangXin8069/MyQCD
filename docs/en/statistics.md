# Statistics

`myqcd.statistics` implements jackknife resampling, deterministic bootstrap
and effective-mass estimates with the standard library only.

## Jackknife

For $N$ samples $x_i$, the leave-one-out estimates and covariance of the mean
are

$$
\bar x_{(-i)}=\frac{\sum_j x_j-x_i}{N-1},
\qquad
\widehat{\mathrm{Cov}}
=\frac{N-1}{N}\sum_i
\left(\bar x_{(-i)}-\bar x\right)
\left(\bar x_{(-i)}-\bar x\right)^T.
$$

## Bootstrap and effective mass

Bootstrap indices are generated by a seeded `random.Random`, so results are
reproducible. The effective mass from a correlator is

$$
m_{\mathrm{eff}}(t)=\log\frac{C(t)}{C(t+1)}.
$$

## Reproduce

```python
import math

from myqcd import statistics

samples = [(1.0, 2.0), (2.0, 4.0), (3.0, 6.0), (4.0, 8.0)]
assert statistics.jackknife_mean(samples) == (2.5, 5.0)
covariance = statistics.jackknife_covariance(samples)
assert covariance[0][0] > 0
assert statistics.bootstrap_indices(4, 5, seed=7) == statistics.bootstrap_indices(4, 5, seed=7)
result = statistics.bootstrap_mean([1.0, 2.0, 3.0, 4.0], 50, seed=3)
assert result["stderr"] >= 0
masses = statistics.effective_mass([math.exp(-t) for t in range(4)])
assert all(abs(mass - 1.0) < 1e-12 for mass in masses)
print(result)
```

## Comparison

| Quantity | MyQCD | Standard |
|---|---|---|
| Jackknife mean | leave-one-out mean | same |
| Covariance factor | $(N-1)/N$ | same |
| Bootstrap | seeded resampling | same |
| Effective mass | $\log(C_t/C_{t+1})$ | same |

The jackknife covariance is the covariance of the mean, not of a single
configuration. Bootstrap resampling does not replace an ensemble or a
continuum extrapolation.
