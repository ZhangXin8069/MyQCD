# `refer/papers` 全量内容总结报告设计

## 1. 目标与边界

本项目将 `refer/papers/INDEX.md` 中登记的 50 篇论文作为唯一论文集合，生成一份中文、16:9 横板、页数不少于 200 页的学术长篇报告。英文学术转排目录与中文译本目录代表同一篇论文，只展开一次；两种目录用于交叉核对正文结构和术语。`Essential_Papers_on_Lattice_QCD_Parton_Physics_latex/` 与 `格点QCD部分子物理精华论文选_latex/` 是已有选集，不在全量论文档案中重复展开。

报告直接消费以下材料：

- `refer/papers/INDEX.md`：论文集合、英中目录、索引页数、arXiv 标识和备注；
- 每篇论文的中文 `main.tex`、`chapters/*.tex`：内容总结的主证据；
- 同篇英文目录的 `main.tex`、`chapters/*.tex`：公式、章节和英文术语的核对证据；
- 每篇 `TRANSLATION_GUIDE.md`、`CONVERSION_GUIDE.md` 与 `AGENTS.md`：来源、转排限制和已知勘误。

当前目录中未发现论文 PDF，因此报告不声称完成 PDF 原文交叉核验；源 LaTeX 中未提供、无法由正文直接推出的数字或结论标记为“未验证”。`.agent.*` 日志和构建缓存属于过程记录，不作为论文科学内容纳入总结。

## 2. 交付物

报告输出到项目 `docs/`，使用不覆盖既有文件的新文件名：

- `docs/report_refer_papers_all_20260828.tex`：可复查的主 LaTeX 文件；
- `docs/report_refer_papers_all_20260828.pdf`：同名可阅读 PDF；
- 报告正文内部保留源目录、章节名称、arXiv 标识和证据状态，保证每条论文总结可回到 `refer/papers` 的具体文件。

本次不提交、不推送，也不删除或改写已有报告、论文转排目录和索引；报告全部验证通过后，按用户追加要求执行本地 `~tag:stab`，不改写已有标签。

## 3. 内容架构

报告采用“总览—主题综合—逐论文档案—交叉结论”的单一叙事：

1. **总览**：解释材料范围、英中目录去重规则、数据来源、证据等级、阅读方法和全库页数结构。
2. **主题综合**：按物理问题组织共同主线：格点规范理论与禁闭；Wilson 流、能动量张量和连续极限；LaMET、准 PDF 与赝 PDF；非微扰重正化与微扰匹配；胶子 PDF、介子 PDF 与 TMD；机器学习采样与随机量化。
3. **逐论文档案**：按 `INDEX.md` 的 50 篇顺序建立统一档案，便于从索引回查，不因主题归类而丢失论文。
4. **交叉结论**：总结从欧氏格点可计算对象到光锥部分子观测量的共同因子化链条、系统误差来源、方法之间的互补关系和可执行的后续核验清单。

## 4. 单篇论文信息单元

每篇论文固定四页，预计 50 篇贡献约 200 页；加上总览、主题综合、交叉结论和附录，目标总页数约 220 页。四页的主结论和证据如下：

### 第 1 页：研究问题与论文定位

- 题名、作者/来源、arXiv 标识、库内英中页数；
- 论文解决的物理问题和必要背景；
- 中文译本摘要的压缩版，保留目标、对象和主要结论；
- 证据等级与来源文件。

### 第 2 页：理论结构与方法链

- 章节级方法路线：输入、定义、假设、核心算符/关联函数、匹配或演化步骤；
- 关键公式或公式族，旁注对称性、量纲、极限和适用条件；
- 数值或解析方法中的关键状态、控制参数和停止/匹配判据；
- 公式来自源文件时保留对应章节路径和行号范围。

### 第 3 页：结果、验证与物理含义

- 论文正文中明确报告的结果、图表或结论，不补造缺失的数值；
- 区分直接结果、由结果推出的判断以及正文没有验证的外推；
- 给出基线、误差、有限体积/离散化/高扭度/重正化等适用限制（源文有说明时）；
- 解释结果对格点 QCD、部分子物理或采样算法的影响。

### 第 4 页：局限、关联与可复查入口

- 论文明确列出的局限和尚未解决问题；
- 与前后相关论文的输入/输出关系，例如“流方法改善重正化”或“匹配将准分布连接到光锥 PDF”；
- 对称性、量纲和极端情形的简短一致性检查；
- 证据清单、完整源路径、英中目录对应关系和需要后续核验的事项。

每页至少有一个主视觉：信息流程使用单列工作流表格，方法关系使用框图，比较使用表格，物理公式使用分行公式链。视觉只表达源材料支持的关系，不使用没有来源的趋势图或装饰性图形。

## 5. 证据与真实性规则

报告统一使用三种状态：

- **确证**：摘要、章节正文、公式、图表或结论在当前源文件中直接可查；
- **推断**：由一个或多个确证内容合理推出，并在文字中注明推断依据；
- **未验证**：缺少 PDF、原始数据、实验复现或源文件证据，不能作为已证实结论。

每个论文档案保留 `claim_id`、`evidence_ids`、来源路径、章节名和行号。英文/中文目录存在差异时，以英文正文结构为核对基准，以中文译本提供中文叙述；差异记录为翻译或转排事项，不擅自修改论文内容。

## 6. LaTeX 与版式实现

- 使用 `ctexbeamer`，保留 `aspectratio=169`、中文字体和报告技能规定的安全边距；
- 每页使用固定 `frame`，不使用 `allowframebreaks`，不让表格、公式等号链或流程箭头在任意位置自动断开；
- 正文/表格不使用 `\tiny` 规避布局；来源行使用可读的短路径，附录给出完整路径；
- 单列工作流表格直接放在 `frame` 内，比较表使用 `tabularx`，跨模块关系使用 TikZ；
- 预先生成 `frame_manifest`，为每页登记 `frame_id`、主张、证据、视觉类型、宽高预算、最小字号、拆页边界和风险；
- 对 200 页以上的重复单元，使用统一宏和经过转义的源文本，减少模板漂移；每篇论文仍保留明确的标题和来源，不用空白页凑页数。

## 7. 验证方案

交付前执行以下验证：

1. 检查 `xelatex`、`ctexbeamer`/`beamer`、`tikz`、`booktabs`、`tabularx` 等工具链；
2. 对主文件执行两遍 `xelatex -interaction=nonstopmode -halt-on-error -file-line-error`，构建文件放临时目录；
3. 用 `pdfinfo` 读取实际页数，要求 `pages_expected >= 200`；
4. 统计 `Overfull`、`Float too large`、`Overfull \\hbox` 和 `Overfull \\vbox`，要求均为 0；
5. 用 `pdftoppm` 渲染全部页面，要求 `pages_actual = pages_rendered = pages_checked`；
6. 逐页检查页边安全区、标题、公式、表格、流程图、来源和页脚，记录 `occlusion_pairs=0`、`clipped_objects=0`、`outside_safe_area=0`；
7. 用 `pdftotext` 抽查标题、论文名、关键结论、来源和中文字符；
8. 对本次新增文件执行 `git diff --check`，并定向确认没有意外修改 `refer/papers` 原文、已有 `docs` 报告或系统配置。

## 8. 已知限制与处理

- 源库没有论文 PDF，不能把 LaTeX 转排内容表述为当前 PDF 的逐页复核结果；
- `INDEX.md` 记录的是 50 篇成对目录的原文转排页数，报告实际页数由新 Beamer 编译结果决定，二者不要求相等；
- 论文之间存在综述与原始研究的内容重叠，逐论文档案保留必要重复，主题综合负责解释重复关系；
- 如果某篇源文件只有很短的摘要或章节，仍保留四页信息结构，但把缺失的结果、数据或验证写成未验证事项，不用虚构内容填充；
- 200 页以上的 16:9 文档适合作为可检索的研究档案，不等同于 10–15 分钟组会演示稿。
